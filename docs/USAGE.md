## ⬇️ 安装与首次使用

应用提供两个安装渠道：

- **Microsoft Store 版（即将推出）：** 上架后可由 Microsoft Store 统一安装和更新。
- **独立安装版：** 从 [GitHub Releases](https://github.com/GaBoron/steam-achievement-translation-installer/releases/latest) 下载安装程序。适合不能使用 Microsoft Store，或习惯手动管理安装程序的用户。

Microsoft Store 版推出后，两个版本的翻译、编辑、备份和恢复功能将保持相同。通常只安装其中一个即可，不建议同时运行两个版本。需要更换渠道时，先退出并卸载当前版本，再安装另一版本；保存在本机数据目录中的设置、缓存、草稿、历史和备份不会因为更换安装渠道而主动删除。

独立安装版直接覆盖安装新版即可。它暂未提供代码签名，Windows SmartScreen 可能首次显示安全提醒，请核对下载来源和 Release 中的 SHA-256 后再运行。即将推出的 Microsoft Store 版将由 Store 安装和更新。

首次打开后，应用会自动检测 Steam 目录并扫描本机成就缓存。也可以在设置中手动指定 Steam 路径，或选择配置 Steam Web API，以补全账号拥有但本机尚无缓存的游戏。

应用以普通用户权限启动。扫描、预览、设置、日志、编辑草稿和导出文件不会触发 UAC；只有确认安装、恢复、写回本地编辑或激活历史修订时，才会请求管理员权限。独立安装版安装软件更新时也会请求管理员权限；Microsoft Store 版推出后，软件更新将由 Store 处理。取消 UAC 后，本次操作会停止，应用仍可继续使用。

## ☁️ 查找和安装社区译本

1. 打开“云端”页，按游戏名或 Steam App ID 搜索。
2. 选择需要翻译的游戏和合适的译本版本。
3. 点击“安装所选”，逐页检查目标语言及 BIN 中的成就文本。
4. 确认后关闭 Steam，让应用完成备份和写入。

同一游戏可能有多个候选译本，请根据版本说明选择。应用会校验文件名、App ID、文件结构和内容，并在确认后再次检查预览文件是否发生变化。

在线列表加载成功后会保留缓存；离线时仍可浏览最近一次结果。游戏名称也会缓存，断网不会影响已有本地文件的操作。

## 🛡️ 管理与恢复

“已管理”页集中显示社区安装、本地导入和本地编辑记录，并标记以下状态：

- 正常
- 可更新
- 文件缺失
- 文件已被修改
- 缺少备份

每项都可查看当前成就文本或恢复安装前文件。目标文件若被 Steam 或其他程序修改，普通恢复会停止，以免覆盖新数据；只有在明确确认后才能强制恢复，且当前文件会先归档。

## ✍️ 编辑本地成就

在“本地”页点击“编辑”，即可按成就 API ID 修改目标语言的名称和说明。

- 可搜索成就，并选择只读语言作为对照。
- 可编辑现有语言或新增合法的 Steam 语言。
- 编辑草稿会自动保存；源文件和成就集合未变化时，再次进入可继续编辑。
- 允许保存不完整翻译，但会明确提示缺失项。
- 保存前会再次检查源文件、成就集合和文本内容。
- 可导出校验后的 BIN，或根目录仅含该 BIN 的标准投稿 ZIP。

写回本机前必须完全退出 Steam。连续编辑可恢复最近几次修改。

## 🧰 制作、导入与贡献翻译

### 使用 Localizer Skill 制作

“本地”页的“制作翻译”会打开 [Steam Achievement Localizer Skill](https://github.com/GaBoron/steam-achievement-localizer-skill)。它负责研究多语言语境、制作翻译、无损写入和验证，并在任务的 `final/` 目录生成：

- `UserGameStatsSchema_<app_id>.bin`
- `UserGameStatsSchema_<app_id>.zip`
- `report.json`

### 导入本地翻译

点击“导入本地翻译”，选择规范命名的 BIN，或根目录仅含该 BIN 的标准 ZIP。应用会检查：

- 文件名与 App ID
- ZIP 单文件结构
- Binary KeyValues 字节级 roundtrip
- 成就内容与 SHA-256

管理器不会修改所选源文件。确认预览后，它会使用与社区译本相同的备份、安装与恢复流程。

### 请求或贡献翻译

没有云端译本时，在搜索页点击“未找到游戏？”，填写 Steam App ID 并导出原始 schema ZIP，再前往 [Steam 成就翻译库](https://github.com/GaBoron/steam-achievement-translation-library/issues/new/choose) 提交翻译请愿。

如果已经完成翻译，可从编辑页或投稿流程导出标准 ZIP，再提交到翻译库。ZIP 根目录只能包含一个 `UserGameStatsSchema_<app_id>.bin`。

导出不会修改 Steam 文件。找不到原始文件时，请先启动对应游戏，让 Steam 生成一次成就缓存。

## 🚩 报告云端文件问题

1. 在“云端”页找到游戏并点击“报告”。
2. 首次使用时绑定 GitHub，并在浏览器中完成授权。
3. 选择“文件可能过期”或“文件可能不生效”，填写说明。
4. 检查最终预览并提交。

报告只包含游戏名、App ID、商店链接、问题类型、说明和可选参考来源，不会上传本机成就文件。提交失败时填写内容会保留。可以随时在设置中解绑；如需同时撤销 GitHub 端授权，请使用设置中提供的授权管理入口。

## 🔄 更新与网络

软件更新按安装渠道分别管理：

- **Microsoft Store 版（即将推出）：** 上架后将由 Microsoft Store 检查、下载和安装；设置页会显示当前渠道，不提供 GitHub 安装程序按钮。
- **独立安装版：** “设置 → 软件更新”可以检查 GitHub Releases 稳定版、查看发布说明、下载安装包并校验 SHA-256。软件不会静默下载，只有点击“下载并安装”后才会开始。

两个渠道使用同一公开版本号，但不会相互安装对方的更新包。云端译本列表和译本内容的更新独立于软件版本，两个版本使用相同来源。

网络设置支持：

- 系统代理、HTTP 代理和 SOCKS 代理
- 自定义 DNS 与下载镜像
- 连接测试
- 离线模式和最近成功加载的云端列表

“设置 → 下载源”可分别拖动调整 `index.json` 与翻译 BIN 文件的来源顺序，应用会从上到下依次尝试。默认索引顺序为 GitHub Raw、jsDelivr、jsDelivr Fastly、StaticDelivr；默认文件顺序为 jsDelivr、jsDelivr Fastly、GitHub Raw。StaticDelivr 只提供索引候选，因为实际验证中其二进制文件响应不适合作为安装器下载源。两个列表可分别恢复默认顺序。

独立安装版无法访问 GitHub 时，软件更新检查失败不会影响扫描、安装、编辑或恢复。Microsoft Store 版推出后，软件更新状态将在 Store 中查看。

## ❓ 常见问题

### 找不到本地游戏

先启动一次对应游戏，让 Steam 生成成就缓存，然后返回应用重新扫描。仍未找到时，在设置中确认 Steam 路径。Steam Web API 可以补全账号游戏库，但没有本机成就文件的游戏暂时不能编辑或安装。

### 游戏名称没有正常显示

名称查询需要网络。检查代理或镜像设置后重新获取；离线时应用会显示已有缓存或 App ID，不影响本地文件。

### 云端列表加载失败

使用设置页的网络测试检查 GitHub、代理或镜像连接。应用会尽量显示最近一次成功加载的列表，恢复网络后可手动刷新。

### 无法绑定 GitHub

确认网络可以访问 GitHub，并及时在浏览器中完成授权。如果授权被取消、过期或原有会话失效，请返回应用重新绑定。

### 报告提交失败

检查网络和报告预览。GitHub 授权失效时，重新绑定后可以继续使用当前填写内容。

### 编辑草稿没有恢复

草稿只适用于同一个源文件和同一组成就。游戏更新、Steam 重建文件或成就列表变化后，旧草稿不会自动套用。

### 无法保存本地编辑

保存前必须完全退出 Steam。若源文件在编辑期间发生变化，应用会拒绝覆盖，请重新进入编辑页并确认最新内容。

### 安装后翻译消失

Steam 或游戏更新可能重新生成成就缓存。重新扫描并安装即可；如果云端译本已经过期或不再生效，请使用“报告”提交问题。

### 恢复被拒绝

目标文件在操作后发生了变化。普通恢复会停止，以避免覆盖其他程序或 Steam 的新数据。确认需要覆盖时可使用强制恢复，当前文件会先被归档。

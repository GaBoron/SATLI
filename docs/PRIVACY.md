# 数据与隐私

[返回项目首页](../README.md)

SATLI 主要在本机处理 Steam 成就文件。扫描、编辑、备份、恢复和 JSON 导出不会自动上传文件或提交译本。

## 本地数据与凭据

默认数据目录为 `%LOCALAPPDATA%\SATLI\`，可能保存设置、缓存、译文工程、编辑草稿、安装与修订历史、BIN 备份、AI 待审结果及用户启用的诊断日志。软件不会主动清空这些用户数据。

可选的 Steam Web API Key、AI API Key 和代理密码通过 Windows DPAPI CurrentUser 加密，仅当前 Windows 用户可解密。AI 设置支持清除密钥，更换服务地址或接口类型后需重新填写。

本地导出不会写回 Steam BIN、发送至 lite 或上传到翻译库；向受保护目录写入时会提示 UAC 授权。

## 网络连接

功能启用或用户主动操作时，SATLI 可能访问：

| 用途 | 访问的服务或内容 |
| --- | --- |
| 社区译本 | GitHub Raw、jsDelivr 等用户配置的目录和文件源，下载后核对文件完整性 |
| 软件与组件更新 | GitHub Releases；独立安装器按需从微软获取运行库；确认安装 lite 后从其官方 Release 下载插件 |
| Steam 数据 | 用户配置 Steam Web API 后补充游戏库；创建 JSON 工程时获取公开成就与游戏名称 |
| AI 参考翻译 | 用户选择的 AI 服务，接收游戏名、App ID、成就 API ID 与相关语言文本；模型测试也会发送测试内容，调用可能收费 |
| 反馈与投稿 | 在默认浏览器打开预填的 GitHub 表单；附件上传和最终提交由用户完成 |

AI 请求不包含完整 BIN 或 Steam 凭据。可选的网页搜索及数据处理规则取决于所选 AI 服务商。

## 诊断日志

日志可关闭，提供“基础”“详细”以及仅本次运行有效的“Debug”级别，用于定位安装、扫描、网络、翻译和插件连接问题。

日志不会主动记录 API Key、代理密码、成就文件正文、AI 请求或回复正文、模型思考摘要及 GitHub 表单预填内容。但详细和 Debug 级别可能包含文件路径、游戏名、App ID、错误堆栈等诊断信息。**分享日志前请自行检查并删去敏感内容。**

## SATLI lite 本机交互

只有用户确认应用或发送译文时，SATLI 才会通过 Steam 目录中的 lite 公开本机接口投递 JSON 请求。请求包含游戏和版本标识、目标语言、成就 API ID 与译文；lite 的回执、请求状态和必要的原始请求记录会保存在本机，以便退出软件后继续追踪。

“已管理 → JSON”会读取 lite 发布的本机译文清单和快照，供查看或打开为草稿。读取和编辑草稿不会修改 lite；发送前需确认，默认不会覆盖已有译文。Steam 关闭时读取的状态可能不是最新的，已确认的请求可在满足条件后排队处理。SATLI 无需常驻。

旧显示桥迁移需单独确认，并在退出 Steam 后移除旧插件文件；现有翻译快照和 BIN 备份不会主动删除。SATLI 不捆绑或自行安装 Millennium，只会在用户选择时打开其官方安装说明。

以上本机交互不会向 SATLI 自有服务器上传译文。强制恢复 BIN 前会先归档当前文件，但仍建议自行备份重要数据。
